# WhatsApp Business API Rate Limits and Queue Design in India

Message volume is not the same as safe throughput. A production integration needs a queue, per-tenant fairness, retry backoff and a way to explain a delayed message to an operator.

## Queue the side effect

Accept a business event, assign an idempotency key and queue the send. Workers should respect the provider response, pause on throttling, retry only transient failures and move permanent failures to a review queue. Never retry an invalid template or an opted-out contact as if it were a network error.

## Protect smaller tenants

Use tenant-aware quotas so one campaign cannot starve support traffic. Keep utility, authentication and marketing workloads visible separately. Monitor queue age, retry count, provider error class and delivery state rather than treating every accepted request as success.
