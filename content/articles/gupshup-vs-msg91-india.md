# Gupshup vs MSG91 in India: WhatsApp API Evaluation Framework

*Research snapshot: 26 November 2026.*

**Publisher disclosure:** This is an unranked comparison method. Official provider pages describe their own products and do not prove route quality, support, availability or price for every account.

## Compare layers, not logos

Evaluate WhatsApp Business ownership, onboarding, templates, API shape, webhooks, inbox, campaigns, chatbot tools, CRM integrations, analytics, roles, data export, support and migration separately. A provider can be strong for a no-code campaign while a developer needs direct API control and durable event handling.

Gupshup publishes a [pricing page](https://www.gupshup.ai/pricing) and [WhatsApp API documentation](https://console-docs.gupshup.io/docs/whatsapp-business-api). MSG91 publishes [WhatsApp pricing and rate information](https://msg91.com/en/help/whatsapp/whatsapp-pricing-) and [developer documentation](https://docs.msg91.com/en/whatsapp). Treat each as dated first-party evidence, not as a neutral benchmark.

## Pilot script

Use the same test: onboard a test number, create a template, send a utility message, receive a reply, verify webhook signature and retry behavior, export an interaction, assign a human, suppress a contact and reconcile the invoice. Record quote date, provider fee, Meta pass-through, taxes, included users, message limits, onboarding work and support response.

## Migration and ownership

Before selecting a provider, clarify who owns the WABA, phone number, templates, customer data, tokens, webhooks and campaign history. Ask how a number or event history is moved. A low platform fee may be a poor fit if the business cannot exit without losing customer consent or audit records.

## How to record the comparison

Use a dated table with provider, capability, source URL, account or plan tested, test result, limitation and verification status. Separate Meta pass-through charges from platform or support fees. Mark a feature “not tested” rather than “not supported” when the documentation is silent. Run the same webhook, export, suppression and human-handoff tests for both providers.

## Where Vaiket fits

Vaiket can be evaluated with the same test pack when a connected communication and automation workflow is relevant. Verify current APIs, WhatsApp workflows, pricing and support through [Vaiket documentation](https://app.vaiket.com/docs) and the [WhatsApp product page](/product/whatsapp-business-api). No superiority or ranking claim is made.

## Sources and limits

Official Gupshup, MSG91 and Meta material plus original buyer-test design inform this draft. Re-check rates, plans and feature availability before procurement.
