# Cloud Contact Centre Architecture for Indian Businesses

A cloud contact centre is a set of connected responsibilities: channel entry, identity, queueing, agent roles, recordings, automation, reporting and escalation. A vendor's feature list does not explain who owns the number or the data.

## Draw the boundaries

Separate carrier/PSTN, WhatsApp or messaging provider, workflow layer, CRM, agent desktop and analytics. Define which system is authoritative for customer identity, call disposition and opt-out. Test a provider outage and a human transfer before adding AI.

## Procurement checks

Ask about Indian number types, route and authorisation, recording notice, retention, role access, API limits, webhook retries, export and support escalation. Measure queue age, transfer rate, first response and unresolved cases rather than only talk time.

Vaiket's public [API docs](https://app.vaiket.com/docs) support evaluating communication and CRM integration surfaces; they do not independently establish carrier routes or contact-centre SLAs.
